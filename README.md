A one-page newspaper front page for Thursday 26 November 2026: a masthead, a full-width lead panel on the Giza fuel-tanker explosion that killed 31 people, and three columns covering Kim Jong Un's tactical-nuclear push, Ukraine's strike on the Savasleyka air base, and the flooded gold mine in Bogor, Indonesia. Every story was verified against live Reuters/AP/CNN reporting. The finished front page is bundled in this repo as `entry.png`; running `main.py` copies it into the output directory named by `MAKEFUN_OUTPUT_DIR` (or a local `out/` folder when the variable is unset), using only the Python standard library.
